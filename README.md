# FOOTFIX

Проект для обувной мастерской FOOTFIX. Веб-приложение для управления заказами, клиентами и процессом ремонта обуви.

## Функциональность

- Управление заказами: создание, редактирование, отслеживание статуса.
- Управление клиентами: регистрация, контактная информация, история заказов.
- Управление процессом ремонта: этапы, стоимость.
- Административная панель: управление персоналом, отчеты, статистика.

## Технологический стек

### Backend (Сервер)
- Фреймворк: Express.js
- Язык: JavaScript (Node.js)
- База данных: MySQL
- ORM: Sequelize
- Безопасность: bcrypt (хеширование паролей)

### Frontend (Веб-интерфейс)
- Язык: JavaScript (ES6+)

## Установка и запуск

### Предварительные требования
- Node.js (версия 14 или выше)
- npm (устанавливается вместе с Node.js)
- MySQL (или другая база данных, указанная в config)
- Git

### Шаг 1: Установка зависимостей
1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   ```
2. Установите зависимости для backend:
   ```bash
   cd myapp
   npm install
   ```
3. Установите зависимости для frontend (если применимо):
   ```bash
   cd sitedb
   npm install
   ```

### Шаг 2: Настройка конфигурации
1. Создайте файл `.env` в корне проекта `myapp` и укажите следующие переменные:
   - `PORT` — порт для запуска сервера (по умолчанию 3000)
   - `NODE_ENV` — режим работы (development/production)
   - `JWT_SECRET` — секретный ключ для JWT-токенов
   - `DB_USERNAME` — имя пользователя базы данных
   - `DB_PASSWORD` — пароль базы данных
   - `DB_NAME` — имя базы данных
   - `DB_HOST` — хост базы данных
2. Пример файла `.env`:
   ```
   PORT=3000
   NODE_ENV=development
   JWT_SECRET=your_super_secret_jwt_key_2024
   DB_USERNAME=root
   DB_PASSWORD=
   DB_NAME=Shoe
   DB_HOST=127.0.0.1
   ```

### Шаг 3: Запуск приложения
1. Запустите backend:
   ```bash
   cd myapp
   npm start
   ```
2. Запустите frontend:
   ```bash
   cd sitedb
   npm run serve
   ```
